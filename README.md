# Maintainr demo repository

> **Public synthetic fixture:** all issue and pull-request content, error and
> security scenarios, and repository policy in this repository are fabricated
> for a hackathon demo. GitHub account authorship is real.

Do not post real credentials, private vulnerability details, customer data, or
production logs here. This repository exists only to demonstrate how Maintainr
turns an issue inbox into a small queue of evidence-backed maintainer decisions.

The demo intentionally includes:

- two pairs of similar reports for duplicate comparison;
- one redacted security-sensitive report;
- one incomplete bug report;
- support, documentation, and feature-request examples; and
- one small pull request about preserving OAuth state.
